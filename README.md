# GibbWise

GibbWise is a Windows budgeting app with monthly budgets, transaction tracking, CSV import, recommendations, savings forecasts, and local-first records.

- Website: https://gibbsllc.github.io/GibbWise-Releases/
- Download: https://github.com/GibbsLLC/GibbWise-Releases/releases/latest/download/GibbWise-Install-Manager.exe
- Releases: https://github.com/GibbsLLC/GibbWise-Releases/releases

This repository holds the public website and installer/update assets only. The application source is private.
